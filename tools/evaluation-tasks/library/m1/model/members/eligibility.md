# Eligibility

Only a registered active [[members/member]] may start a new loan. Suspension prevents new borrowing but preserves every existing loan, including its due date and open state. It does not prevent returning a loan. Restoring active status removes the suspension restriction; all other borrowing conditions still apply.

Lending must enforce this membership rule when admitting a new loan, rather than relying on membership status being checked somewhere else.
