# Tier

A membership tier. It sets the monthly fee and the discount on machine usage. The monthly fee does not apply to a paused member, whose fee [[members/membership|the membership rule]] states.

| Value | Meaning |
| --- | --- |
| `basic` | Monthly fee 2500 cents, usage discount 0 %. |
| `plus` | Monthly fee 4900 cents, usage discount 10 %. |
| `pro` | Monthly fee 9900 cents, usage discount 25 %. |
