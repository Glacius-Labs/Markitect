## Blocking

1. **Check placement.** Every Implement handoff runs the full project tests, which leaves cannot pass (`cmd/library` belongs to `library`, `realization/` to Root). Children get `markitect check` only; Root's handoff gets the full suite, as arm M's `ChecksFor` does (`internal/project/prepared.go:334`).
2. **Stale acceptance.**
   - Reopen every ancestor that has any handoff, not only accepted ones (`referee.py` about line 219).
   - Refuse accepting a stale child.
   - `root_final` requires that no Manager is stale.
3. **Reviews go to direct children only.** Today a raw push can make a child "accept" its parent.
4. **Protected inputs.** Refuse a work push whose diff against base touches `.markitect/` outside `.markitect/registry/`.
5. **False deadlock and lost events.**
   - Count owed reviews in `is_open`, using a reviewed flag per handoff.
   - Deliver events by cursor and acknowledgement instead of popping them on `wait`.
6. **Nudge loop and dead supervisors.**
   - Nudge only on new events, or with backoff and a cap of about 3 nudges without progress, then report the Manager stuck.
   - The host fails the Run as soon as any Manager container exits early.
   - Wrap the supervisor loop in retry.
7. **Secret scan.** Before publishing, scan transcripts, wip refs and Git objects of `run.git`, check logs and `target.git` for access, id and refresh tokens, as `tools/comparison/runner.py:197` does. Quarantine on a hit.
8. **Orphaned Runs.**
   - Add `stop.py LABEL` (`docker rm -f -v` by label, plus the network).
   - The referee exits shortly after the final result.
   - Start the host detached; the token limit lives only in the host today.
9. **Codex parity with arm M.** Copy M's Codex switches from `tools/comparison/runner.py:55-63`:
   - `--disable multi_agent/multi_agent_v2/apps/memories/...`
   - `agents.enabled=false`
   - `cli_auth_credentials_store="file"`

   Also copy the CPU, memory and pids limits.
10. **Token counting.** `turn.completed.usage` on `codex exec resume` may be cumulative. Confirm on a two-turn session, then use deltas or the last total per session. Also: P1 on the full tree and a Windows host need the owner's recorded OK.
