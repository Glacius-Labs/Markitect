# Publication boundary

S2 retires the previous live-tree publisher together with the old runtime contracts. Standalone Run retains independently reopened candidates and closes all live resources. It does not publish or commit into the user's checkout.

S3 must compare the actual captured baseline Census and guard, independently reopen exact stored acceptance after closure, transfer only that candidate and read back target bytes. Starting HEAD identity alone is insufficient when accounted ignored/untracked input exists. See the [accepted architecture](../../../docs/design/v1-execution-architecture.md) and [delivery plan](../../../docs/implementation-plan.md).
