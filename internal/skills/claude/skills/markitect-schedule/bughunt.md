Start the `markitect-builder` agent with the message "Hunt bugs." and wait for it. It has the `markitect-reviewer` agent hunt beyond what `markitect status` lists and record each bug it finds, as `fail` on the Definition it breaks or as `spec-problem` on the nearest Definition when the spec does not cover it. The builder repairs what failed and has the reviewer verify again, until nothing it can settle is left, or the list has not got shorter for three rounds.
