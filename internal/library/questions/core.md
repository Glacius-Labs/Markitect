# Questions: core

Questions across documents that a model built on the core module should answer. Each answer comes from the model alone, with a citation.

- Which role is responsible for each rule, and does that role exist?
- For each decision, what was weighed against it, and what evidence would reopen it?
- Which goals have a measure, and which document says how it is measured?
- Which terms are used in the model without a document that defines them?
- Which activities name each role among their participants, and is any role named by none?
- Which rules apply to the same thing, and can they hold at the same time?
