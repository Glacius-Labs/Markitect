# Questions: core

Questions across documents that a spec built on the core package should answer. Each answer comes from the spec alone, with a citation.

- Which role is responsible for each rule, and does that role exist?
- For each decision, what was weighed against it, and what evidence would reopen it?
- Which goals have a measure, and which document says how it is measured?
- Which terms are used in the spec without a document that defines them?
- What may each role not do, and does any other document ask it to?
- Which rules apply to the same thing, and can they hold at the same time?
