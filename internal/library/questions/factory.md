# Questions: factory

Questions across documents that a spec with the factory package should answer. Each answer comes from the spec alone, with a citation.

- Which agent performs each step of each process, and does its document say whether it asks?
- Who starts each agent and observer, with which model, and on which schedule?
- Who owns each Area, which class does it have, and who usually plans there?
- Which roles does each person hold, and which dashboard answers their question?
- Which rule does each agent follow when it deviates from its usual way, and at which level does it stop?
- Which observer watches each source that the rules rely on, and what does it never put in a report?
- Which meeting takes which briefing, and who takes part?
- What does each agent change, and does any other agent change the same thing?
