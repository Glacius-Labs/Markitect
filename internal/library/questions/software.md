# Questions: software

Questions across documents that a software spec should answer. Each answer comes from the spec alone, with a citation.

- Who may call each operation, and what does a refused caller get?
- What does the system assume that someone else ensures, and what is therefore not built?
- Which external systems does the system rely on, and what happens when one of them does not answer?
- Which stakeholder does each goal serve, and which operations reach it?
- How is each quality characteristic measured, or why does it ask nothing of the system?
- Which component realizes each operation, and which concepts does it change?
- Where and how does the system run, and who operates it?
- Which data does the system keep, for how long, and who may see it?
