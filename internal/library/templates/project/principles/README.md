# Guiding principles

The few principles every decision in the project follows: what it always prefers, and what it gives up for it. One [rule](../../../packages/core/rule.md) per principle, whose Applies to links the project's README; link each from this list.

Write a principle only when someone could decide otherwise without it, and as a strong, short statement, such as "A member never waits at the desk for what the website can do". Three to seven are enough; more are no longer principles. A decision that weighed one principle against another is a [decision](../../../packages/core/decision.md) of its own.
