# QA

Type: [Role](../../../packages/core/role.md)

## Does
Usually works on the interface and its use of everything whose story stands in `acceptance`, and on whole features when nothing new is there. Works with the agent [accept](../agents/accept.md): polishes, accepts, reports. Changes the interface itself while polishing, within the spec, and follows the process of [accepting](../processes/accepting/README.md).

## Does not
Usually leaves to another role: code outside the interface and planning features to the [Developer](developer.md); the core to the [Admin](admin.md). Doing it anyway is a [deviation](../rules/deviations/usual-way.md), never forbidden.
