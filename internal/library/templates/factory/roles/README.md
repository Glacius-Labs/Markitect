# Roles

The human roles of the way of working: Admin, Developer and QA. One [role](../../../packages/core/role.md) per document. Its Does says where the role usually works and which agents it usually uses; its Does not says what another role is usually there for. Nothing is forbidden: the documents describe the usual way, and work outside it is a [deviation](../rules/deviations/usual-way.md). Which person holds which role stands with each [person](../people/README.md).

- [Admin](admin.md)
- [Developer](developer.md)
- [QA](qa.md)

A project changes a role through a finding of type Factory, for example when deviations of a role pile up with good reasons.
