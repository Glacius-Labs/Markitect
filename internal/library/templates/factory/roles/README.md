# Roles

The human roles of this project. One [role](../../../packages/core/role.md) per document. Its Does says where the role usually works and which agents it usually uses; its Does not says what another role is usually there for. Nothing is forbidden: the documents describe the usual way, and work outside it is a [deviation](../rules/deviations/usual-way.md). Which person holds which role stands with each [person](../people/README.md).

By default there is one role, the [Admin](admin.md), who does everything; a project with one person needs no other. A project that splits the work adds a document per role here, links it from this list, and narrows the Admin's document to what stays with it. A project changes a role through a finding of type Factory, for example when deviations of a role pile up with good reasons.
