# Classes

The catalog of classes of Areas. One [class](../../../packages/factory/class.md) per document; link each from this list. A class is optional: it groups Areas and sets rules for the group. A class says who usually plans there, never who may; breaking its Never is a [deviation](../rules/deviations/usual-way.md).

The classes the standard ships:

- [Factory](factory.md): the way of working.
- [Cross-cutting](cross-cutting.md): a rule for everyone and the observer that checks it.
- [Infrastructure](infrastructure.md): pipeline, environment, delivery, dependencies.

The classes of the product belong to the project: add them here when Areas of the product follow shared rules.
