# plan-items

Type: [Observer](../../../packages/factory/observer.md)

## Observes
How the items of the plan move.

## Source
The plan in `.markitect/plan/` and its Git history on `main`, read locally. Observed to: the commit up to which it observed.

## Worth a statement
Stories `in progress` without a commit for 3 days; blocked stories, and since when; claimed features without movement for 5 days; stories `ready` for 3 days and not started; smell stories whose references grew, with the count before and now. The thresholds are starting values.

## Never in the report
Customer data and secrets; causes and recommendations, which are the Triager's and the Analyst's.

## Schedule
daily

## Model
Sonnet, effort high
