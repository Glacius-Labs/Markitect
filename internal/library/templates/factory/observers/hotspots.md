# hotspots

Type: [Observer](../../../packages/factory/observer.md)

## Observes
Where development jams in the structure.

## Source
The Git history of `main`, read locally. Which paths count as the core, the Rules of the core's Area say. Observed to: the commit up to which it observed.

## Worth a statement
The last 14 days against the 14 before: for each module, how many stories touched it; files touched by three or more stories; files changed again within 3 days of their merge; parallel changes, the same file changed on both sides of a merge, as an approximation of merge conflicts, which needs real merge commits; every change to the core. Generated files and generated lists do not count. The thresholds are starting values.

## Never in the report
Customer data and secrets; causes and recommendations.

## Schedule
weekly

## Model
Sonnet, effort high
