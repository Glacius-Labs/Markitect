# Confirm

Type: [Step](../../../../packages/company/step.md)

## Description
When Builder and Reviewer agree, the Reviewer runs the targeted tests itself and confirms, with the tool, each place in the spec that the story names ([one trace](../../rules/building/one-trace.md)). The `confirm` is the Reviewer's yes, no extra stop.

## Performed by
The [Reviewer](../../agents/review.md) of the last round.
