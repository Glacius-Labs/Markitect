# Accept

Type: [Step](../../../../packages/company/step.md)

## Description
The QA accepts the story, and it goes to `done`. A feature is accepted as a whole once its stories are accepted; a feature without an interface is accepted by whoever worked it out. What the QA finds problematic instead, it reports.

## Performed by
The [QA](../../roles/qa.md), with [accept](../../agents/accept.md); for a feature without an interface, its [Developer](../../roles/developer.md).
