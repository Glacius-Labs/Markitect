# Accepting

Type: [Process](../../../../packages/company/process.md)

## Trigger
A story has landed on `main` and stands in `acceptance`; or nothing new is there, and whole features wait to be looked at. [Norman](../../agents/norman.md) starts [accept](../../agents/accept.md) for the QA.

## Steps
1. [Take](take.md)
2. [Polish](polish.md)
3. [Review](review.md)
4. [Accept](accept.md)

## Result
The story is `done`; a feature whose stories are all accepted is accepted as a whole, and only then may it go into [production](../../rules/building/production.md). Friction and anything fundamental went back into the circle.

## Responsible
The [QA](../../roles/qa.md); for a feature without an interface, whoever worked it out.

## Involved
The agent [accept](../../agents/accept.md) works with the QA; a fresh [Reviewer](../../agents/review.md) checks the result of the polishing.
