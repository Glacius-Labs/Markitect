# Check

Type: [Step](../../../../packages/company/step.md)

## Description
A Reviewer compares the target picture with every level above it, up to the spec as a whole ([every level fits the levels above](../../rules/plan/target-pictures-fit.md)). When one does not fit, work on it continues.

## Performed by
A fresh [Reviewer](../../agents/review.md), started by the [Architect](../../agents/architect.md).
