# Plan

Type: [Step](../../../../packages/company/step.md)

## Description
The agent plans on its own and tells abstractly how it means to realize it in principle, and names the stumbling blocks here. For a feature the plan is the cut into stories, with their order, their dependencies and what belongs into the first version; for a story it is the tasks. For the spec, the plan is the stories that carry the change, each in a feature of the Area that covers the place it changes, so that it lands through a story like every other change. Every story it creates gets its dependencies set explicitly ([dependencies](../../rules/plan/dependencies.md)). When the stories can only be cut with many dependencies, it writes that down as coupling for the report at the end.

## Performed by
The [Architect](../../agents/architect.md).
