# Areas

The Areas of this project's plan. One [Area](../../../packages/factory/area.md) per document, each written down explicitly, with its owner and, where it has one, its [class](../classes/README.md); link each from this list. This folder belongs to the project and starts empty.

Fill it when you set up the way of working. Areas usually follow the architecture, since both divide what should stay as independent as possible, but planning may be cut differently from what is built. A project usually has an Area for the core, one per module, one for infrastructure (pipeline, environment, delivery, dependencies), one for the factory, the way of working itself, with the class [Factory](../classes/factory.md), and cross-cutting Areas such as security and architecture with the class [Cross-cutting](../classes/cross-cutting.md). Every Area has a Developer as its owner, and in `.markitect/plan/` a folder with its standing feature `housekeeping` ([housekeeping](../rules/plan/housekeeping.md)).
