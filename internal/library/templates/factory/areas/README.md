# Areas

The Areas of this project's plan. One [Area](../../../packages/factory/area.md) per document, each written down explicitly, with its owner, what it covers and, where it has one, its [class](../classes/README.md); link each from this list. This folder belongs to the project and starts empty.

Fill it when you set up the way of working. An Area covers parts of the product and building blocks of the architecture; Areas usually follow the architecture, since both divide what should stay as independent as possible, but planning may be cut differently from what is built. One Area covers the factory part, the way of working itself, with the class [Factory](../classes/factory.md). Every Area has a person as its owner, and in `.markitect/plan/` a folder with its standing feature `housekeeping` ([housekeeping](../rules/plan/housekeeping.md)).

Name here the one Area that takes the findings whose Area is unclear: `Unclear Area: ` and a link to it.
