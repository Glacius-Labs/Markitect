# People

The persons who work on this project. One [person](../../../packages/factory/person.md) per document, with the [roles](../roles/README.md) they hold; link each from this list. This folder belongs to the project and starts empty.

Fill it when you set up the way of working: one document per human, named after the person, such as `ada.md`, holding their roles. Who is not Admin or Developer is usually QA. Areas, meetings and dashboards link here.
