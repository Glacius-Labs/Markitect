# The work folder

The rules for what lies in `.markitect/`: the context, the findings, the plan and the briefings, and how agents write there. The types of these documents stand in the package factory: [Report](../../../../packages/factory/report.md), [Finding](../../../../packages/factory/finding.md), [Feature](../../../../packages/factory/feature.md), [Story](../../../../packages/factory/story.md), [Briefing](../../../../packages/factory/briefing.md).

- [Names in the work](names.md)
- [One context folder per kind of agent](context-per-agent.md)
- [One per session](one-per-session.md)
- [Drop what you notice](drop-what-you-notice.md)
- [Checkpoints](checkpoints.md)
- [Straight to main](straight-to-main.md)

To add a rule here, write a document of type Rule in this folder and link it from this list; to change one, raise a finding of type Factory.
