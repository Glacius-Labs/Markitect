# Improves itself

Type: [Rule](../../../../packages/core/rule.md)

## Applies to
[The factory](../../README.md)

## Rule
When a rule, an agent or an observer does not suffice, it shows as a finding of type Factory, and it is changed. The way of working is never changed on the side.

## Example
Deviations of the QA pile up with good reasons: the finding of type Factory changes the [QA](../../roles/qa.md) document, so that small fixes become usual for the QA.
