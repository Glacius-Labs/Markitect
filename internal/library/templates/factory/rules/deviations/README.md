# Deviations

Nothing in the way of working is forbidden. Every role and every agent has a usual way of working, and a deviation from it is warned about, given a level and noted, never blocked. One mechanism for everyone: humans and agents, every Area, every level.

To add a rule here, write a document of type Rule in this folder and link it from this list; to change one, raise a finding of type Factory.
