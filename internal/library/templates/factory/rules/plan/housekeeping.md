# Housekeeping in every Area

Type: [Rule](../../../../packages/core/rule.md)

## Applies to
[The plan](README.md)

## Rule
Every Area has a standing feature `housekeeping` for stories that belong to no feature: bugs, cleaning up, maintenance, smell analyses. There is one per Area, so that it stays visible where such work piles up. Housekeeping is no process of its own: its stories are built like every other story, only without the planning, since nothing is left to conceive.
