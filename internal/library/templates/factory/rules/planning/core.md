# The core

Type: [Rule](../../../../packages/core/rule.md)

## Applies to
The Area of class Core; [planning](../../processes/planning/README.md)

## Rule
The core is treated like a temple: it decides more than anything how well and how fast the project develops. In the core an Admin usually plans; afterwards it is built like everywhere else, with no check before `main`, and stories with fixed tasks run alone there too. After every change to the core, what depends on it is checked, and everything against the spec; until an agent is named for that check, the planning that makes the change names it in its report as open.
