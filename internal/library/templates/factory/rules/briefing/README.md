# Briefing

The rules for what reaches the humans and when. The agent that writes the [briefings](../../../../packages/factory/briefing.md) is the [Briefer](../../agents/brief.md).

- [Importance decides when something is shown](when-shown.md)
- [Critical stays on top until done](critical-until-done.md)
- [People decide in conversation](decide-in-conversation.md)

To add a rule here, write a document of type Rule in this folder and link it from this list; to change one, raise a finding of type Factory.
