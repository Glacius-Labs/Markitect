# Meetings

The recurring meetings of this project, in which people decide in conversation ([decide in conversation](../rules/briefing/decide-in-conversation.md)). One [meeting](../../../packages/factory/meeting.md) per document; link each from this list. This folder belongs to the project and starts empty.

Fill it when you set up the way of working. A project usually starts with two, named `daily.md` and `weekly.md`: a daily meeting whose briefing holds what is shown daily, and a weekly one whose briefing holds what is shown weekly ([when shown](../rules/briefing/when-shown.md)). Each meeting's briefings lie in `.markitect/briefing/` in a folder named like its document. Meet only as much as needed: for planning, the state, ideas, problems and questions, and only about what is built, so that everyone knows roughly what a feature is. The [Briefer](../agents/brief.md) prepares each meeting's briefing, and [Norman](../agents/norman.md) reminds on the day.
