# Core

The types that every project needs to write down what it knows, wants and has decided, and who answers for it. Copy this folder into a spec as it is, or change it to suit the project.

## Contents

- [Concept](concept.md): a thing the project knows and names, with rules of its own.
- [Decision](decision.md): a choice that was made, with its reason.
- [Goal](goal.md): what should be reached, stated so that it can be checked.
- [Role](role.md): someone who acts, named by what they usually do.
- [Rule](rule.md): something that holds and that someone could get wrong.
- [Term](term.md): a word with a fixed meaning in this project.
