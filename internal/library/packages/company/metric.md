# Metric

A number the business watches, such as loans per month. Take it for each figure someone is accountable for. Take a [goal](../core/goal.md) instead for the aim itself; a metric is how to see whether it is reached.

## Definition
What is measured and how it is computed. Example: `Loans per month: the number of loans made between the first and the last day of the month.`

## Target
The value aimed at, as a link to a goal or as a number. Example: `1,200`.

## Source
Where the number comes from. Example: `The loan register of the desk system.`

## Responsible
The role that watches it, as a link. Example: `[Head librarian](../team/head-librarian.md)`.
