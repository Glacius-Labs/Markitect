# External system

A system outside the project that it works with, such as a payment service. Take it for each system the project relies on or talks to and does not build. Take a [component](component.md) instead for a block the project builds itself.

## What it is
In one sentence. Example: `The town payment service, which takes the yearly membership fee.`

## Expected
What the project relies on it to do. Example: `Confirms a payment within one minute, or says that it failed.`
