# Interface

A way to reach the system: a user interface, an API or a command line. Take it for each such way, with its users and what it offers them. Take an [operation](operation.md) for one thing a caller can do, which an interface lists.

## For
Who uses it, as links. Example: `[Member](../team/member.md), [Librarian](../team/librarian.md)`.

## Offers
The operations it makes available, as links. Example: `[Renew a loan](../domain/renew-a-loan.md)`.
