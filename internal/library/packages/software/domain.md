# Domain

What the system does: the things it manages and what can be done with them. Take it for the system as a whole, or for one part of it, as the README of a folder. A large domain splits into parts, each a folder with its own README of this type. Take the [context](context.md) instead for what is given from outside.

## Concepts
The things the system manages, as links to [concepts](../core/concept.md), one per line. Example: `[Loan](loan.md)`.

## Operations
What callers can do, as links to [operations](operation.md), one per line. Example: `[Lend a copy](lend-a-copy.md)`.

## Rules (optional)
The [rules](../core/rule.md) that hold across the domain, as links. Example: `[At most five open loans](five-open-loans.md)`.

## Parts (optional)
The parts below, each as a link to its README. Example: `[Reservations](reservations/README.md)`.
