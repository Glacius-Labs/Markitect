# Rule

Something that holds and that someone could get wrong if it were not written down.

## Applies to
What it governs, as links. A link to a folder's README means everything in that folder.

## Rule
What holds, in a few sentences.

## Responsible (optional)
The role that watches over it, as a link.

## Example (optional)
A short case that shows it. An example illustrates and fixes nothing.
