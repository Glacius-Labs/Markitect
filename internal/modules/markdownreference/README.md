# Markdown Reference Projection Module

Contract: `markitect-markdown-reference@1.0.0` is a statically composed Projection Module for target `markdown`, with entrypoint `markdown-reference`. Its private Core-facing input contains normalized Schemas, exact selected Definitions and selected ProjectionPolicies, plus explicit target, check, observation and prior-record facts. It does not read repositories, parse raw YAML, import sibling Modules, or infer additional scope.

For a valid repository-relative target prefix, the Module owns exactly `<prefix>/canonical-projection.md` and proposes one regular Git mode `100644` artifact. Its independent format is a Markdown reference bundle: separately marked JSON blocks contain every supplied Schema contract and each selected Definition and policy with exact identity, purpose and spec. Stable sorting makes bytes independent of input order. This compact catalog layout differs from the existing Markdown prose renderer while preserving supplied canonical meaning.

The Module rejects a non-Markdown target, an invalid prefix, a path outside its explicit allowed roots, malformed or over-limit semantic input, and ambiguous ownership. It returns `escalate` when selected scope or target inventory is incomplete, prior ownership is missing or inconsistent, or retired output is present. It returns `no-op` only when the complete observed inventory, complete prior record and current successful verification all bind the exact desired bytes and regular-file mode. Otherwise it returns `work` with the single desired file. It never writes, deletes, reads the repository, or declares owner acceptance. Host owns static composition, path authorization, Apply and independent verification.

`examples/module-replacement/` is the source fixture package/configuration. It reuses unchanged canonical Rule, Process, Responsibility and Gate inputs for both the existing and alternate package bindings. The alternate package carries no copied private implementation; static Host composition resolves its declared entrypoint to this Module.
