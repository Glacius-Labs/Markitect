# Outcome

An Outcome Definition states one thing that holds once an [[std/Operation]] has been performed, a [[std/Reaction]] has applied, a [[std/Scenario]] has run or a [[std/Task]] has been carried out, named for what holds. What no Outcome of an Operation names does not change.

**Leaves in:** the [[std/State]] of a [[std/Concept]] the Outcome leaves an instance in, where it moves one. Once the Outcomes of a Concept name the States they leave in, every State of it is named by one.

Verified when it is shown to hold afterwards.
