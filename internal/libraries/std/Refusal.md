# Refusal

A Refusal Definition states how one refusal, or several answered alike, reaches the person or program using a [[std/Page]], a site or an [[std/Interface]]: what is then shown, or where it leads. A refusal a page rules out, by offering only what is allowed, has none.

Verified when the refusal reaches the user as stated.
