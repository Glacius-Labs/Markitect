# Invariant

An Invariant Definition states one thing that holds at all times for every instance of a [[std/Concept]], named for what holds. Every [[std/Operation]] preserves it. **Derived from:** the [[std/Constraint]] or [[std/Rule]] it follows from, where there is one.

Verified when no Operation can break it.
