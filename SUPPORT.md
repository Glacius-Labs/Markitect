# Support

## Getting help

For general questions about Markitect, open a GitHub issue and describe what you are trying to do. Include the Markitect version, operating system, relevant command, and a minimal example when possible. Remove credentials, secrets, and private repository content before posting.

For unexpected behavior, choose the **Bug report** issue form. For a proposed capability or improvement, choose **Feature request**. Start with the [documentation](README.md#documentation): the [project workflow](docs/guides/project-workflow.md) describes how to use Markitect, with troubleshooting, and [CONTRIBUTING](CONTRIBUTING.md) how it is developed.

## Project-specific questions

Adopting repositories own their spec, checks and acceptance policy. Markitect issues can clarify the product contract; questions about a particular repository's policy belong with that repository's maintainers.

## Distribution

Source changes in this repository do not change an installed release. Check [GitHub Releases](https://github.com/Glacius-Labs/Markitect/releases) for published distributions and their documentation.
