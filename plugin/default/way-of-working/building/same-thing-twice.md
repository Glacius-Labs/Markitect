# The same thing twice is a smell

Type: [Rule](../../core/rule.md)

## Applies to
[The Builder](../team/builder.md), [the Reviewer](../team/reviewer.md), [duplication](../observing/watch-duplication.md)

## Rule
When the same thing is built in several places, that is a smell: it is built once and used from there. The watch on duplication looks for it regularly; Builders and Reviewers report it when they notice it.
