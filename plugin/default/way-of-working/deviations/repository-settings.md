# The repository settings grant the usual

Type: [Rule](../../core/rule.md)

## Applies to
[Every role an agent fills](../team/README.md)

## Rule
The repository's settings refuse nothing and grant what is usual: reading, writing in one's own working folder, building and testing, committing, pushing one's own branch, bringing a reviewed story to `main`, and writing the work straight to `main` ([three ways to main](../work/straight-to-main.md)). What is [critical](critical.md) and recognizable as a command stands on "ask" there, so an agent running alone gets no further and aborts. What is an ordinary file change, such as a secret in a commit, the settings do not catch: the Reviewer looks for it before anything lands ([review](../review/review.md)), and the watch on [the deviations](../observing/watch-deviations.md) catches what slips through. The exact list arises when the project sets up its settings.
