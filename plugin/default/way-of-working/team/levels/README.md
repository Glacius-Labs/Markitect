# Levels

What the agents run on: three levels, by how demanding the work is, and behind them the AI models of each provider. An agent names a level; only the level names AI models.

## Contents
- [Workforce](workforce.md): for work that follows a plan or fixed steps.
- [Specialist](specialist.md): for work that judges.
- [Expert](expert.md): for the most demanding work.
- [Claude](claude/README.md): the AI models of this provider.
- [Codex](codex/README.md): the AI models of this provider.

## How to fill it
To work with a further provider, add a module for it here with its AI models, and one line to each level. To take another AI model for a level, change the link in the level.
