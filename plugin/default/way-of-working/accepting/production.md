# Production

Type: [Rule](../../core/rule.md)

## Applies to
[Accepting](accepting.md), [the Reviewer](../team/reviewer.md)

## Rule
A feature may go into production only once it is accepted; until then it lies on `main` switched off ([off until accepted](off-until-accepted.md)). A person releases, never an agent, as [release](release.md) says: before it, a Reviewer checks everything against everything, the stories against the feature, the feature against the model. Going into production otherwise is a [critical](../deviations/critical.md) deviation.
