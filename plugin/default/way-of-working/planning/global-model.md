# The model as a whole

Type: [Rule](../../core/rule.md)

## Applies to
[Planning](planning.md), [Admin](../team/admin.md)

## Rule
The model as a whole is usually changed by the role whose document says so, by default the Admin; when someone else does it, that is a deviation of level `high`. An addition by the Project manager that only writes down what follows from what is decided is no deviation ([the three exits](../triage/three-exits.md)), nor is a statement a person decided in so many words, which the Project manager enters as it was said ([record](../recording/record.md)). A change to the model as a whole is worked out in a planning and built through stories like every other change; there is no check of its own after it: a human checks the plan and the changed model, agents build, and what the application shows flows back as a finding.
