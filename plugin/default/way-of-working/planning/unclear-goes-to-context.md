# What is unclear goes into the context

Type: [Rule](../../core/rule.md)

## Applies to
[Planning](planning.md), [the Architect](../team/architect.md)

## Rule
When it is unclear on the way how something should be, or an interface turns out to be missing, the agent drops it into the context, and it becomes a finding that lands in the right place. Nothing unclear is guessed. Meanwhile the person takes the next topic or asks a colleague directly.
