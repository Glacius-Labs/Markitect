# Briefing

Type: [Artifact](../../core/artifact.md)

## For
Everyone, in the daily and the weekly meeting: what is to decide?

## Offers
1. Critical: as in the [Overview](overview.md). The Assistant says it always.
2. Daily: the `pending` findings shown daily ([when shown](../briefing/when-shown.md)). The Assistant says only the person's own.
3. Weekly: the `pending` findings shown weekly. The Assistant says nothing of it.
4. Without decision: what went into the plan without a decision since the last briefing, and what was added to the model because it follows from what is decided. The Assistant says the person's own, each in a sentence.

One line per finding: its title, type and module, with a link to it. The view reads the findings itself; of the Briefer's [briefing](../briefing/briefing.md) it takes only the date, "today's briefing is there".
