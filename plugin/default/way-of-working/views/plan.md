# Plan

Type: [Artifact](../../core/artifact.md)

## For
Everyone: what is there, who owns it, how far is it?

## Offers
1. Tree: module, feature, story; for each module the role responsible, for each feature its owner, for each story its state and the number of its tasks. The Assistant says nothing of it.
2. Feature page: the documents of the model its stories realize, as links, and which of them are not built yet; the stories in their order, their dependencies, what is blocked. The Assistant says nothing of it.
3. Unclaimed: features without an owner that someone can take. The Assistant names them when it proposes where to begin.
4. Ahead: the documents of the model that a story changes which has not landed, by module, each with that story and its state: what the model says and is not built yet ([the model runs ahead](../plan/the-model-runs-ahead.md)). The Assistant says it when asked.
