# Every level fits the levels above

Type: [Rule](../../core/rule.md)

## Applies to
[The plan](README.md), [planning](../planning/planning.md), [the Reviewer](../team/reviewer.md)

## Rule
The model is the target: there is no target picture beside it. Every change to the model fits the levels above the place it changes: a document fits its module, a module the one above it, up to the model as a whole. What a document says is to be read like an interface or a responsibility, not as a specification of every detail. When a change chafes, the question is whether the model wobbles or the artifacts are the problem.

## Example
The change "a loan can be renewed once" fits the module Lending and the model's rule on lending periods.
