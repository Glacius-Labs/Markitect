# Watch

Extends: [Activity](../../core/activity.md)

An activity that returns, in a rhythm or whenever its source has something new, which its Trigger says, and looks at one topic in one source: it states what it sees there, with numbers and places, and nothing else ([a watch only states](only-states.md)). Take it for a topic worth looking at again and again; a single look is a story, and a second topic is a second watch. The text before the first section says what it states and from which threshold.

## Source
Where the source lies and with which tool it is read, and what marks how far a run has observed, a commit, a run or a file, where the next run begins.
