# The plan items

Type: [Watch](watch.md)

State how the items of the plan move: stories `in progress` without a commit for 3 days; blocked stories, and since when; claimed features without movement for 5 days; stories `ready` for 3 days and not started; smell stories whose references grew, with the count before and now. The thresholds are starting values.

## Participants
[Observer](../team/observer.md)

## Trigger
Daily.

## Steps
[Observe](observe.md)

## Result
A report with the statements, or only the checkpoint when there was nothing to state.

## Source
The plan and its Git history on `main`, read locally. Observed to: the commit up to which it observed.

## Never in the report
Customer data and secrets; causes and recommendations, which are the Triager's and the Analyst's.
