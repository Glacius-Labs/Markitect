# The way of working

How this project is developed: who works on it, how the circle turns, how work is planned, built and accepted, and which rules hold. Humans work on the model; agents bring it into the artifacts; what strikes on the way flows back through one entrance. It is a module of the model like any other, written in the same general types. The skills of the agents, the views, the handbook and the place where the work lies are built from it, as code is built from the product's modules. Every activity an agent does is realized as a skill ([a skill per activity](team/a-skill-per-activity.md)); the module that holds the activity names where its skill lies, here for the provider Claude, and a project that works with another provider names that provider's place as well.

## How to read it
Start with the [principles](principles/README.md) and [the circle](circle.md). Picture a head of state with no time for details: observers report, a staff sifts the reports and writes a briefing, the head decides what matters and is told at once when something is critical. Then read the modules in the order above. Each module holds everything about its topic: what its things are, who acts, in which steps, and which rules hold.

## How to fill it
This module is a complete way of working: a project with one person that applies it can run it as it is. [Set up the project](set-up.md) leads through what belongs to the project: the people with their roles in [the team](team/README.md); the role responsible for each module of the model, in that module's README; the [meetings](briefing/meetings/README.md); the watches for the project's own sources in [observing](observing/README.md); and rules for kinds of modules in [the plan](plan/README.md). Then complete the list of what is [critical](deviations/critical.md) for the project when setting up the repository's settings.

## How to change it
The way of working improves itself, never on the side ([improves itself](principles/improves-itself.md)). A change starts as a finding of type Process, from anyone, and runs through the circle like any other: it is planned in the module it changes, the Architect writes it into these documents, and what is built from them, the skills among it, is rebuilt. Giving a role another level, or a level another AI model, needs no build: whoever starts an agent reads it from its document ([starting an agent](team/starting-an-agent.md)).
