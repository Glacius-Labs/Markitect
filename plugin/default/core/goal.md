# Goal

What should be reached, stated so that one can check whether it was. Take it for each aim of the project, the business or a part of it. Take a [decision](decision.md) instead for a choice already made, and a [rule](rule.md) for what holds all the time.

## Goal
What should be reached, with a measure where there is one. Example: `Members renew a loan without visiting the desk.`

## By (optional)
The date by which it should be reached, as `YYYY-MM-DD`. Example: `2027-03-31`.
