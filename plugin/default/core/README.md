# Core

The general types: the kinds of document every model is written in. Each type says what it is, when to take it, and which sections its documents have. A model owns its copy and may change it.

## Contents
- [Concept](concept.md): something the project knows and names.
- [Term](term.md): a word with a fixed meaning.
- [Rule](rule.md): something that holds.
- [Decision](decision.md): a choice with its reason.
- [Goal](goal.md): what should be reached.
- [Role](role.md): who acts, named by what they usually do.
- [Actor](actor.md): who fills roles; the base of person and agent.
- [Person](person.md): a human who fills roles.
- [Agent](agent.md): an agent that fills a role.
- [Level](level.md): how demanding an agent's work is, and which AI model serves it.
- [AI model](ai-model.md): one AI model of one provider.
- [Activity](activity.md): something that is done again and again, by someone.
- [Artifact](artifact.md): something that is built for someone to use, whatever its form.
