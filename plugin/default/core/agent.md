# Agent

Extends: [Actor](actor.md)

An agent that works on the project. Take one per role an agent fills, so that an agent has one task. Giving a role a more or a less demanding level is changing one link here.

## Level
Type: [Level](level.md)

The level it runs on, as a link to a [Level](level.md). Example: `[Workforce](levels/workforce.md)`.
