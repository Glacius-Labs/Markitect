# Actor

Someone who works on the project and fills roles: a [person](person.md) or an [agent](agent.md). This type is the base of both. A [role](role.md) says what someone is there for; an actor says who fills it, and that stands here, with the actor, not with the role. Processes, tasks, rules and modules name roles, never an actor.

## Roles
Type: [Role](role.md)

The roles this actor fills, each a link to a [Role](role.md), one per line. Example: `[Librarian](librarian.md)`.
