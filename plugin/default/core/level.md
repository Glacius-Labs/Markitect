# Level

How demanding the work is that an agent does, named in plain words, such as "workforce". A level is what an agent runs on: it names, for each provider the project works with, the [AI model](ai-model.md) that serves this level there. Take one per kind of demand, not one per AI model.

## AI models
Type: [AI model](ai-model.md)

The AI model that serves this level at each provider, each a link to a [AI model](ai-model.md), one per line. Example: `[Claude Sonnet](claude/sonnet.md)`.

## Effort
The effort the AI models run with. Example: `high`.
