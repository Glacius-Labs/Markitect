# AI model

One AI model of one provider, written down once, so that its name stands in one place. Agents do not link an AI model directly: they link a [level](level.md), and the level names the AI model of each provider. So a provider can be added or exchanged without touching an agent.

## Provider
Who offers it. Example: `Claude`.

## Name
The AI model's name as that provider knows it. Example: `Opus`.
