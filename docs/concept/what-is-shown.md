# What is shown and what is not

Each run below ran once, on Sonnet, so none of them is a rate. The runs with the texts of 0.32.2 and 0.33.0 ran on committed test projects outside any repository, the earlier ones on study projects, some with an earlier form of the flow. What is not shown is covered by tests only, and the [roadmap](../roadmap.md#current-steps) tries it next.
