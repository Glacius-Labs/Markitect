# Project artifact inputs

This guide described the retired Project/Domain `spec.files` and `ContextRun` interfaces. Their original contracts and examples remain in the immutable [v0.14.1 guide](https://github.com/Glacius-Labs/Markitect/blob/v0.14.1/docs/documentation.md) and [source tree](https://github.com/Glacius-Labs/Markitect/tree/v0.14.1).

Current model-first project ownership is declared by Manager Artifacts. Markitect treats those paths as opaque files; it does not parse source code or infer document semantics. See [Architecture](architecture.md#project-artifact-boundary) and [Project workflow](project-workflow.md).
