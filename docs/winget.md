# Retired WinGet package

The v0.5.0 manifests, install/upgrade scripts and download-dependent workflow are retired with the old releases. Their exact source is available at [the pre-retirement revision](https://github.com/Glacius-Labs/Markitect/tree/1f4a1ede214d05fd2fee615b3905207df7702426/packaging/winget), and [the original package record](https://github.com/Glacius-Labs/Markitect/blob/1f4a1ede214d05fd2fee615b3905207df7702426/docs/winget.md) retains its source and validation limits.

The old catalog proposal was closed on 17 October 2026: [PR #445055](https://github.com/microsoft/winget-pkgs/pull/445055). Retiring its downloads supplies no supported installation path. Future catalog work requires a new verified release and a separately reviewed submission; the [distribution tool](../integration/README.md#release-contents-and-verification) can export new manifests.
