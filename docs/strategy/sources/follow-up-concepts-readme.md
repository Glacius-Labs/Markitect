# Markitect — Follow-up Concept Documents

These documents capture the concepts discussed after the strategic positioning document.

1. **AI-First Executable Engineering Constitution**  
   Architecture as canonical law for autonomous AI implementation; strong statements, valid-change grammar, extension points, exceptions, and architecture changes.

2. **Reusable Architecture Patterns and Project Shapes**  
   Reusable Vertical Slice / Clean Architecture / DDD patterns; Template vs Pattern vs Package; ongoing conformance; architecture packages and versioned pattern migration.

3. **"Copy Me" Engineering Style Discovery**  
   AI-assisted reverse engineering of implicit architectural preferences from repositories and review decisions; Observe → Infer → Review → Canonize; onboarding and style distillation.

These are discussion documents for implementer review, not implementation mandates.
