# Content packages

This guide documented the retired Project/Domain content-package contract. Its package manifests, archive format, pinning rules and examples remain available in the immutable [v0.14.1 source](https://github.com/Glacius-Labs/Markitect/tree/v0.14.1), including the original [content-package guide](https://github.com/Glacius-Labs/Markitect/blob/v0.14.1/docs/content-packages.md).

Current Markitect source does not expose that authoring feature. Current release package and bundle preparation are described in the repository [distribution guide](../integration/README.md); that release tooling has a distinct purpose and format.
