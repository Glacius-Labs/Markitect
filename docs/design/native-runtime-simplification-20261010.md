## Intended behavior

- Ordinary setup selects a working native Codex runtime with inherited user
  environment and authentication, a supported Windows backend, and normal tools.
- Each Manager, helper and independent review gets its own native chat and owned
  working directory. Users give work, rather than configuring permission details
  for every role or file.

  Git candidates, independent review, Verify, original-turn recovery and guarded
  Apply. Normal file work within an authorized task uses that existing authority.
- Assessment has usable tools and its own writable scratch without changing the
  delivered candidate. Genuine out-of-scope decisions remain explicit.
