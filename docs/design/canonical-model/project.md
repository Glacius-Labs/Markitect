# Project

A **Project** is the common entry point for the canonical model of a software project. It brings together the definitions that describe the project as a whole.

## Purpose

A Project establishes the shared context for its definitions and determines which descriptions together form its canonical model. Its role is comparable to a `.slnx` solution file: it provides a starting point from which the associated structure can be understood.

## Description

A Project has a name and a description of its purpose. It refers to the definitions that belong to it, establishing the scope of the project's canonical model.

The project's descriptions follow its chosen subject areas and organization. They can be arranged across documents and directories that make their responsibilities clear. The Project brings these descriptions together through its references.

## Example

**Tasks** is a Project for a local application that records, lists and completes personal tasks. Its purpose is to help a person keep track of their work. Its associated definitions describe the application's subject matter, behavior, structure and development.
