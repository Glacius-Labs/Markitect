# Workflow

A **Workflow** describes a repeatable sequence of activities, their participants and their intended outcome.

Current review status: the [need for process descriptions](consolidation.md#arbeitsziel-und-wackelkandidaten) is open. A domain or operational process may describe intended project behavior; Apply's agent coordination and conventional pull-request steps do not automatically belong in the canonical model. This working definition does not establish that a Workflow type is needed.
