# Project-local projections

This page documented the experimental Project-local Projection API bundled with v0.14.1. That API is not in current source. Its original contract and examples are preserved in the immutable [v0.14.1 usage guide](https://github.com/Glacius-Labs/Markitect/blob/v0.14.1/docs/projections.md) and [release source](https://github.com/Glacius-Labs/Markitect/tree/v0.14.1).

The canonical Projection alpha is separately described in the retained [historical guide](history/canonical-projections-v0.14.1.md). Current product boundaries and source status belong to [Architecture](architecture.md) and the [implementation roadmap](implementation-plan.md).
