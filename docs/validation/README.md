# Validation records

These reports preserve the exact scope, inputs, source references and outcomes stated by each assessment. A report is evidence for that recorded run; its date or a `pending`/`NOT RUN` statement does not describe today's source status. Use the [delivery plan](../implementation-plan.md) for current source scope and candidate chats and PRs for actual integration state. Earlier validation records of retired source are not kept on Main; the [archive index](../archive.md) lists them.
