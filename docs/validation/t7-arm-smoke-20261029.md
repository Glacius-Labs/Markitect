**What launch 1 found**, all fixed before launch 2:

- **The suite's token count was wrong for the 2.0 arm:** 7,160 output tokens instead of 68,137. Stream-json repeats a response's usage as it stood when each content block was written. `tokens.py` now counts a session that left only stream output from the `result` line each `claude -p` process ends with.
- **Review findings** on the arm and the network check (an independent complete-diff review, run beside the launch): a failed gate or owner input that does not compile delivered the unchanged start, which would score as a right stop on a planted defect; the event reader could stop silently; networks were allowed by name; a cleanup error could overwrite a delivered result; a failed start could make the reported model "mixed".
- **Found while validating the fixes on real reference starts:** copying the model kept the source files' timestamps, so Git's stat check saw Library M2's one-character change of `loan-policy.md` as unchanged and the model change was never committed. The arm now copies without metadata and checks that its commit equals the task's model byte for byte.
