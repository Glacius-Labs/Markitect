# Apply design before DEC-056

These seven documents are the detailed Apply design as it stood before [DEC-056](../../concepts/register.md#dec-056-recursive-reconciliation-with-a-shared-workspace) of 19 October 2026: the core protocol, execution contract, configuration, port contracts, journal, Go architecture and rebuild plan. The recursive-reconciliation concept [manager-apply-concept.md](../../design/canonical-model/manager-apply-concept.md) and the implemented contract [manager-apply-runtime.md](../../design/canonical-model/manager-apply-runtime.md) supersede them.

They are kept for the decisions, reasoning and failed attempts they record, not as a contract. Where they differ from the concept, the runtime contract or the source, those win. Their text is unchanged apart from the note at the top of each file and corrected links.
