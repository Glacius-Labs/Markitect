# P09 — Regression gates and one normal product smoke

Maintain risk-based regressions for compiler/model validation, strict DTOs and privacy, setup/onboarding, shared CLI/MCP, Git deletion and rename, freshness and ownership, failed cleanup, original root errors, retry task identity, and exact native recovery without replay. Keep focused tests with implementation. Mock/protocol results are source evidence, never authenticated product acceptance.

Before Main, require a stable integrated source/build/install/onboarding path and current documentation; the relevant regressions; independent review with material findings closed; and required Linux/Windows PR/CI gates on the actual final head.

Run one small combined A01 journey on the unchanged integrated candidate using the existing authenticated Codex installation and Luna High. It covers normal setup and a short Work Item/model change, two small independent Managers with observed overlap, at least one real fresh helper, independent review and Verify, guarded Apply, and concrete resumption of the persisted original turn/workspace without replay. Repair an actual compiler defect if encountered; negative compiler/recovery cases belong in regressions. Use a disposable owned project. Do not introduce a Case Study framework, comparison, scores, private fixtures, semantic prompting, a large domain application, or an artificial failure matrix.

The four-hour job window is a protective ceiling. A02/A03 are deferred until after Main and are not automatically started. The overall three-job/twelve-hour/256-start allocation remains finite, includes failed and nested attempts, and never refills automatically. Preserve original purposes and consumed failures in the ledger. Unknown usage or partial total native accounting alone does not block Main; concrete unresolved active children, ownership or safety defects do.

Acceptance records the source/build/config identities, actual logs and owned handles, observed start attempts and failures, overlap/helper/review/recovery evidence, checks, candidate and applied outcome, timing and explicit unknowns. No fabricated smoke pass or shortened required checks. Broader scientific/playground comparisons remain stopped and are not a Main gate.
