# P06 — Real Managers, helpers and independent review

Make every selected Manager a separately started real agent with fresh task context and the useful project/Git workspace from P03. Preserve exactly-once scheduling of model-declared Managers. Support normal scoped native helper/subagent delegation inside a Manager and separate fresh reviewers; remove the blanket helper-disabled limitation. Helpers cannot duplicate an existing Manager's ownership or approvals. Typed requests/proposed results alone do not prove a real agent ran.

Designer integrates shared orchestration with P04. Current `planManagers`/`runOrResume` orders selected Managers serially; implement actual concurrency for independent responsibilities with dependencies and integration ordering explicit. Record actual starts, parent/child identity, terminal states, task/model/effort/config, elapsed work and available usage. Handle bounded nested parallelism, pending children, cancellation, failures and uncertain termination; do not mark a parent complete while owned child work remains unaccounted for. Keep executor and reviewer context separate and review actual candidate/model/check evidence. Manager independence must give real context advantages while supplying the dependencies needed to work correctly.

Acceptance: deterministic scheduling/recovery tests plus one permitted actual job with at least two independent Managers performing real parallel work, a real native helper and an independent reviewer. Show distinct context/thread handles and useful outcomes; prove no duplicate scheduling or fabricated assent. Preserve refusal/failure and unknown telemetry honestly. Host permissions are cooperative local boundaries, not claimed OS isolation. Do not weaken task scope or hide normal tools merely to simplify receipts.
