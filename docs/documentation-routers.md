# Documentation routers

This guide described the optional Project/Domain documentation-router feature. Its path selection, link normalization and diagnostic contract remain in the immutable [v0.14.1 guide](https://github.com/Glacius-Labs/Markitect/blob/v0.14.1/docs/documentation-routers.md) and [release source](https://github.com/Glacius-Labs/Markitect/tree/v0.14.1).

Current source documentation ownership is described by the [Project workflow](project-workflow.md) and repository [documentation maintenance guide](development/documentation.md). Markdown links in an adopting repository do not define product ownership or semantic dependencies.
