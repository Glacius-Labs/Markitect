# Owner goal: a stable V1 justified by data

Date: 24 October 2026. Source: the owner's direct message in a Claude Code session while the coordinator drove the V1 implementation. The owner statement is verbatim; the translation and the recorder's notes are labeled.

## Owner statement (verbatim)

> Unser Ziel ist es ein stabiles V1 zu haben und es mit Daten rechtfertigen zu können, dass es stabil und besser als ein Agent macht alles ist. Mache alles was dafür nötig ist und melde dich sobald du überzeugt bis

English translation: "Our goal is to have a stable V1 and to be able to justify with data that it is stable and better than one agent doing everything. Do everything necessary for that and report back as soon as you are convinced."

## Recorded meaning

Recorder's interpretation: V1 acceptance needs two kinds of data.

- Stability: repeated native runs of the reference scenarios on the frozen final source, with predeclared repetition counts and honest pass rates.
- Comparison: a controlled study of Markitect against the owner's primary baseline in the [measurement guide](../../guides/measurement.md#quality-first-comparative-evaluation). That baseline is ordinary documentation with the same intended meaning, given to one coding agent with the same model, effort, resources and independent hidden assessment.

This authorizes that study as bounded evidence work under the standing evidence authorization; the measurement guide itself had not scheduled one. The coordinator reports to the owner only when the data convince it, with the uncertainty and limits stated.
