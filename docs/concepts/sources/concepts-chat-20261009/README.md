Die Nutzerbeschreibung ist der Ursprung dieser Konzeptaufnahme. Die Konzeptnotizen besitzen ihre Aufbereitung; sie ersetzen weder die [Architektur](../../../architecture.md) noch die [Roadmap](../../../implementation-plan.md). Änderungen an der Interpretation sollen den Ursprung erhalten und ihren eigenen Status kenntlich machen.

## Fortlaufende Aufnahme und spätere Auswertung

Die ergänzende Nutzeranweisung aus dem ursprünglichen Chat sieht eine fortlaufende Sammlung vor. Relevante Konzepte, Ideen, Strategien, Annahmen und Begründungen werden dem Concepts-Chat vor der dortigen inhaltlichen Antwort weitergegeben. Die Sammlung dient als Arbeitsgrundlage für eine spätere gemeinsame Auswertung; erst dann wird entschieden, was daraus gemacht wird.

Für jede neue Aufnahme bleiben Nutzerformulierung und Herkunft erhalten. Eine Interpretation des übergebenden Chats ist getrennt von einer eigenen Interpretation des Concepts-Chats zu kennzeichnen. Herkunft ist nur so genau anzugeben, wie sie tatsächlich übergeben wurde.

Änderungen erhalten Anlass und Bezug zur früheren Aussage. Widersprüche bleiben mit beiden Aussagen sichtbar, bis eine begründete Klärung vorliegt. Eine neuere Aussage überschreibt eine ältere nicht still; eine ausdrückliche Revision kann deren Geltung ändern und wird als solche festgehalten. Eine tatsächliche Entscheidung braucht ihren Entscheider und ihre Grundlage. Notizen und Interpretationen werden durch ihre Ablage nicht zu Entscheidungen.

Die Sammlung begründet keine neue Roadmap oder Implementierung. Bloße Empfangsbestätigungen und Rückmeldeketten sind für diese Zusammenarbeit nicht erforderlich.
