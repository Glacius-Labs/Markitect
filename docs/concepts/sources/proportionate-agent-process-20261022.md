# Proportionate Agent process

Direct owner statements in the concept chat, 22 October 2026. Quotations are verbatim; the context and disposition below are recorder notes.

## Practical baseline

> Du musst so überlegen, normalerweise würde jemand einem AI Agent nen Prompt geben und einfach darauf vertrauen, dass er korrekt ist. Wir müssen hier jetzt nicht wieder in einen unendlich komplizierten Prozess abdriften, nur weil wir erreichen wollen, dass mehrere Agents von verschiedenen Blickwinkeln darauf schauen und hoffentlich dadurch für mehr Konsistenz sorgen

## Concept review and coordination

> Genau. Prüfe das aktuelle Konzept auf dieser Basis und schlage konkret vor, was wir vereinfachen oder streichen sollten. Halte diese Leitlinie im Konzept fest und informiere den Apply-Ablauf-Chat. Noch keine Implementierung.

## Scope clarification

> Der Apply Ablauf Chat steuert die Implementierung. Also "Noch keine Implementierung bezieht sich nur auf deinen Chat, nicht auf seine Ausführung".

## Recorder disposition

The [vision](../../vision.md#proportionate-agent-process) records the accepted guideline, reaffirming DEC-002. The [Apply workflow review](../../design/canonical-model/manager-apply-workflow.md#proportionate-process-review-22-october-2026) owns the concrete recommendations; the request does not itself adopt every proposed removal. The concept chat changes documentation only. `Apply-Ablauf nachvollziehen` continues to direct implementation within its authority; this documentation neither pauses its existing work nor replenishes provider budgets.
