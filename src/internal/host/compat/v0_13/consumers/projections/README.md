# Projections Module

The Projections Module evaluates an explicit, finite contract for local representations of selected canonical resources. It receives a normalized Core semantic model, exact contract/configuration digests, an opaque fixed file snapshot, optional registered deterministic-renderer bytes, and explicitly supplied verification evidence. It returns a deterministic plan with source provenance, target digests, policy results, contract/check status, and diagnostics.

The contract names exact source GraphKeys, a representation, materializer identity and mode, exact project-relative target paths, named Project checks, allowed implementation freedom, and explicit contract dependencies. A dependent contract inherits drift or incomplete status from each prerequisite, with a diagnostic naming the prerequisite; this is bounded status propagation over the validated acyclic configuration graph, not execution ordering or a scheduler. It supports registered deterministic bytes and AI-authored candidate bytes as distinct paths. AI target presence alone is incomplete evidence; named checks must be bound to the same immutable model snapshot, intent, contract, and exact target digests. Evidence identity is recorded, but this pure Module cannot authenticate who ran a check or prove what that check semantically establishes.

This Module owns no file acquisition, renderer or check execution, candidate authorization, file writes, CLI behavior, or Project interpretation. Host supplies those inputs and composes the result with renderer observation, artifact accounting, configured checks, and guarded Apply. A plan is review evidence bound to inputs; it is not owner approval. A policy waiver remains visible in PolicyResults and must not be described as policy-passed. Convergence is limited to the configured targets and evidence; it does not establish correctness of unassessed behavior or files.

The Module imports Core and its own package only. It does not import Host, Infrastructure, Tooling, or sibling Modules. Its source is an unreleased addition; the published v0.13.0 release remains unchanged.

A selected check can itself be an AI-owned test or no-op. This Module evaluates supplied check evidence, not independence, full dependencies or semantic sufficiency. Projects must establish stronger checker ownership independently; the synthetic Dispatch proof does so separately. No argv analysis or new obligation language is implied.
