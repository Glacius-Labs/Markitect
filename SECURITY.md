# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to [hello@glaciuslabs.com](mailto:hello@glaciuslabs.com) with the subject `Security: Markitect`. Identify the affected version or commit and give a short impact summary; we can arrange a suitable channel for detailed reproduction material. When this repository is public and GitHub's **Report a vulnerability** action is available on its **Security** tab, that is also a private reporting channel.

Do not report a vulnerability in a public issue or pull request, or include secrets and exploit details in a public channel.

## Scope

Reports should identify a security issue in Markitect itself or its published distribution. Markitect executes Project-declared checks with the caller's local authority; those commands are project inputs and are not sandboxed by Markitect. For general usage questions or ordinary bugs, use the channels in [SUPPORT.md](SUPPORT.md).

## Updates

This policy applies to the current source repository. Supported release versions and distribution details are listed on [GitHub Releases](https://github.com/Glacius-Labs/Markitect/releases).
