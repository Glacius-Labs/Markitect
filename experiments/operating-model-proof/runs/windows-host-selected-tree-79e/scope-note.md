# Windows selected-tree acquisition diagnosis

The Host timeout was cumulative subprocess work. `LoadSelected` started one `git ls-tree --long` process per selected path. The focused baseline trace recorded 570 such processes; the longest observed Git child was 577 ms, so the trace did not indicate one hung child. The change batches only the already validated exact literal pathspecs, capped by operand count and a conservative Windows UTF-16 command-line budget. It keeps the selected-path result checks, all metadata-before-content checks, and repository identity probes before and after acquisition.

On the fixed base `79e6b133d71426f1a69b4701d9d7ee0fbd468787`, the focused Host test took 87.78 seconds without instrumentation. After batching, it passed in 32.308 seconds. The complete `internal/host` package passed in 496.551 seconds under Go's unchanged default timeout; `internal/infrastructure/source` passed in 47.403 seconds. These are package and focused-test results only; this run did not execute or claim `go test ./...`.
