## Pre-run binding

Before dispatch, store an external manifest with original source-tree revision and source-manifest hash; each fresh export's file-tree hash; task prompt, AGENTS, policy copy, and model/package hashes; Task 1 Skill resource edit and compiled Context hash; Task 3 UseCase Context hash; Task 2 reconstructed base/candidate revisions, exact archive hashes, Context/Impact raw stdout, stderr, exit codes and hashes; candidate CLI version/hash; SDK/runtime; and hidden oracle/evaluator hashes. The Task 3 Context and Task 2 analysis outputs do not exist in the historic evidence tree; generate them from the newly rebound trees and do not claim they are frozen until hashed. Freeze evaluator scaffold before agents, keep it hidden and identical across arms. Any change after the first run requires a new experiment identity.

Task 2 permits Arm A to extend the existing application architecture tests for selected Validator presence. The same request asks both arms to keep executable enforcement coherent and retain before/after failures. Arm B already has the finite package policy for declared Validator links; neither kind of gate proves the other representation automatically. This prevents a deliberately weak simple baseline. Additional test/selection upkeep is measured separately.
