# Pressure observed in the matched comparison

No new Core primitive is justified. These are observations from [the completed comparison](../../docs/validation/agents-md-vs-markitect.md), with the original pilot evidence preserved. Classification is a future investigation boundary, not an implementation plan for extra language features.

Fix the study environment before drawing cost or productivity conclusions. |

Namespace/reference friction and stale narrative task prompts from the original pilot remain follow-up observations. This study rebound the known conflicting Skill task text before freezing; it did not repeatedly measure YAML authoring errors or prove a need for another authoring abstraction. Incoming ownership, fan-out quantification, mixed relation cycle groups, selectors, allowlists and composition were not resolved or newly justified here.

The next experiment should match old/new policy history in both arms, repeat ordinary and governance tasks on another adopter, instrument actual model/tool/token counters where possible, and collect real reviewer decisions and sustained upkeep. A simpler guidance/test setup remains the baseline until measured governance value earns the added model/package machinery.
