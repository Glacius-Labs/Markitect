# AGENTS.md and Markitect comparison

Status: experiment design in preparation; task-visible Context and Impact artifacts and the external run manifest must be bound before dispatch. No comparison agents have run.

## Question and scope

Compare two adopter-owned ways to guide work in the same public MyMeetings source subset: a short root `AGENTS.md`, and the existing Markitect package/model with a task-specific compiled context. There are exactly two arms per task and three tasks (six fresh runs total). This is not a rerun of the earlier source-only baseline and is not a productivity or safety benchmark.

The tasks are (1) a Query returning attendees plus guests, (2) remediation of the failing v2 selected-Command Validator policy, and (3) exposing attendee fee-paid status from Meetings-owned state. The task prompts are in `tasks/`; independent acceptance criteria are in `oracles/` and must stay outside each agent's checkout and input packet.
