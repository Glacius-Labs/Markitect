# Case playground: historical execution generation

The executable comparison harness, its fake agents, provider integrations,
method setup and container build belonged to the previous product generation.
Their complete source and usage remain at the immutable
[5ff3206917fa3b7482d9daedb903d57a919f56b8 Git tree](https://github.com/Glacius-Labs/Markitect/tree/5ff3206917fa3b7482d9daedb903d57a919f56b8/experiments/case-playground).
The former fake-product workflow is retired with those consumers. It cannot
exercise the canonical v1 preparation CLI or prove delegated realization.

The [cases](cases/), [independent evaluation assets](evaluation/) and
[recorded container inventory](container/inventory/) retain their original
bytes and scope. Registrations, results and historical evidence remain with
their original source bindings, including locally retained ignored outputs.
No new comparison, provider invocation or study is authorized by this record.

Current implementation work follows the [delivery plan](../../docs/implementation-plan.md).
The separate [Library playground](../library-playground/README.md) owns its
unchanged independent oracle and bounded transport checks. The packaged source
smoke in `tools/smoke` checks actual canonical M1/M2 read-only preparation;
it does not implement the Library or establish Apply acceptance.
