# Q1 setup: shared intent replay and clarification v1

Protocol version: 2026-10-07-Q1-v1. Applies equally to Conventional Agentic, Markitect Classic, and Markitect Government before each cell's first implementation.

## Actor instruction

As part of the setup already included in your cell, briefly restate the intent currently released for this cell. Use any ordinary format already available to your work, including Markdown planning. Finish and record it before the first implementation change. Identify the released source documents and their cutoff; summarize the terms, rules, priorities, and freedoms they actually state; separate direct statements from your assumptions; and list questions that could change the required behavior. Do not describe future task cards as known requirements. You may continue when a question concerns an existing freedom or does not affect required behavior. Keep the work within the cell's existing setup and resource limits.

## Shared observation and clarification

1. Before the cell starts, the coordinator binds the same public input release and cutoff for all three arms. For each matched start condition, use only the common brief, shared architecture note, and currently released task card supplied to all three arms; include the same cell-specific Brownfield evidence packet when applicable. Bind their exact versions or hashes. These documents state the current task cutoff; the rubric governs assessment and is not an additional task requirement. Record the exact source versions or hashes in the cell record. Do not add future cards, private oracle facts, unannounced priorities, or method-specific requirements.
2. The actor saves its short restatement in its existing setup/planning area before changing implementation files. Preserve the source references, explicit assumptions and open questions. Record the saved artifact and time with the ordinary cell evidence; no new session, extra allocation, or free review is created.
3. If clarification is requested, the coordinator may point all arms to the same already released sentence or document location. It may quote or repeat that released material without adding an interpretation, preference, or example that supplies a missing decision. Record the question, cited source, response, participants, time, and active effort under the common intervention policy. Apply that policy identically in all arms.
4. If the published inputs do not answer a question that affects required behavior, leave it open. Do not infer user approval from an actor's restatement, an independent review, or a coordinator's agreement. Follow the existing shared intervention, escalation, and stop rules; the actual intervention and time remain in the cell record. A real user response, if one occurs under those rules, is recorded as such.
5. After the restatement is frozen, an independent assessor may compare it with the released inputs: fidelity to stated terms/rules/priorities, preservation of stated freedoms, source traceability, and clear separation of assumptions and unresolved questions. Report findings as evidence for Q1 and existing rubric dimensions; this procedure adds no weight or business requirement. The assessor's finding is not a user's acceptance and is not fed back as coaching during the cell.

This procedure measures a short replay of known intent. It does not test open-ended idea elicitation, settle missing decisions, add task requirements, or establish long-term maintainability. Existing task cards, fixtures, hard gates, outcome weights, and arm-specific method obligations remain the bound versions.
