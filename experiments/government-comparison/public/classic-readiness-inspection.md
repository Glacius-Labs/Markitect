`runtime/classic.py` exports `inspect_packet(packetPath)`, `probe_command(binaryPath)`, `native_command(action, ...)`, and `run_native(spec, timeout_seconds=180)`. `native_command` returns a shell-free `{argv, cwd, expectedReport, timeoutSeconds, automaticRetries, productSourceSha}` object for the documented CLI actions. Every call is one fresh process; the common wrapper must persist argv, stdout/stderr bytes, exit code, wall time, timeout state and runtime digest. The helper caps each process at 180 seconds, and performs no retries.

The available native sequence is model/reconcile inspection, controller proposal, Execute, externally reviewed exact digest, guarded Apply, fresh Verify from the saved Apply result, and read-only Audit. The canonical/controller path is experimental alpha. The required scoped Markdown policy preparation in the published Commerce smoke is explicit fixture setup that repeats the existing release-test preparation; it does not model the study's real project intent. The source smoke used a protocol test double and synthetic known fixture bytes; it is not agent or semantic evidence.

Product gaps remain explicit: no native Scientist role or `--request/--result` interface, no general persistent resume or study stop, no provider/model/auth provisioned by the product, no common shared trial-budget enforcement, and no authenticated Apply reviewer identity. Provider usage is optional and absent from the packet's synthetic smoke. Markitect uses the local caller's process/filesystem authority. A Codex sandbox flag alone does not establish an effective OS boundary for the whole workflow. Neither proves selected-scope privacy, semantic quality, human acceptance, or reliable unattended operation.

The common wrapper can launch `version` as its read-only probe. Stateful operations require an external runtime JSON with pinned Codex executable/script/model and separate Executor and Verifier invocations; that runtime/provider has not been probed here. Setup, model/policy preparation, human review, retries/errors, and coordination must be charged by the common trial ledger. Classic is not ready for live study until those pins and the real runner/budget/context boundary are frozen and checked.
