# Disposable Government positive fixture

This fixture is a bounded process-integration probe, not a study cell or a
quality claim. Its deterministic Python role program speaks the documented
`agentexec.Invocation`/`Response` JSON protocol and performs fixed byte checks.
The native Government queue must create the actual run, role, vote, and
promotion records. The role program does not write product files, emit
Government reports, or declare human acceptance.

Before a run, bind `order.yaml` to the Constitution digest returned by the
accepted Government binary's read-only `inspect` action, commit the resulting
Order, and set the managed active ref to that exact commit. Configure a single
Ressort in the runtime and bind all three native roles.
