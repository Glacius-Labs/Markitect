The protocol names the two Government Ressorts and requires their actual mandates, evidence, and explicit assent. The activation ledger reserves before a native start, counts failed starts and evaluators, and checks per-task/per-trial/overall ceilings, stage age, and the four-actor limit. It requires a closed preceding stage and specifically requires task 5 to pass before task 6. The unchanged release script accepts a cutoff and materializes only cards through that cutoff; the Q1 setup binds the same currently released sources and prohibits future-card coaching. The protocol accurately labels host separation as cooperative and usage/provider identity as unavailable rather than claiming stronger evidence.

## Execution dependencies to preserve in the record

- The envelope and mailbox tests exercise synthetic fixture messages. They establish reservation/transport behavior only; they do not show that a pinned Government or Classic CLI can invoke this bridge or that real Ressort roles return valid product responses. The bridge preserves response bytes and checks correlation/role identity, leaving product response validation and method semantics to the pinned product. Record an actual product invocation/response before treating either mechanism as executed.
- `native_mailbox.py` accepts only alphanumeric `runId` values. The supplied fixture uses `abc123`; the reviewed material does not establish the pinned product's generated `runId` grammar. Confirm a real invocation satisfies this constraint before relying on the bridge. If the product emits another schema-valid form, adapt the path handling to that documented form before live use.
- The admission ledger is a Scientist-operated recorder, not an OS/tool-level launch gate. `release.py` can materialize any requested cutoff, while the ledger separately blocks task activation until its predecessor is closed (and task 6 until task 5 passes). Thus no future/private input and reservation-before-start remain procedural duties on the single dispatcher; preserve the per-release manifest/hash and dispatch receipts and invalidate a cell if a boundary is crossed. This is consistent with the protocol's explicit cooperative-isolation limitation.
