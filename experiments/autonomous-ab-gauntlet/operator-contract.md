# Mechanical native operator

Each project operator owns only its project run records and isolated actor workspaces in the external frozen arena. The operator may prepare envelopes, dispatch fresh actors, preserve exact responses and available receipts, read actual public-check outcomes, finish turns, and record resulting commits. It must not change application/governance bytes, provide semantic advice, inspect hidden oracles, or accept owner decisions.

Dispatch one actor with `fork_turns: none` and no model/effort override. Supply only the current envelope's `actor_prompt`, exact workspace, and common isolation rules. The actor receives no other arm, prior actor conversation, future card, product source or evaluator. It must not delegate. The inherited default Markitect working directory is outside the assignment; every shell operation uses the explicit actor workspace. No network or interactive owner questions are needed. A required owner decision is reported and left pending.

Use the ordinary authorized sandbox escalation for Git, harness and build commands when the current execution identity cannot access a current-user-created arena/cache. The unscored native smoke exercised this path. Do not modify global Git trust, user configuration, credentials or execution rules. This is the same scope and approval mechanism in both arms; an actual approval rejection is preserved as a runtime outcome rather than bypassed.

Run at most two leaf actors concurrently per project, for a global maximum of six. Alternate A-first/B-first by project/trial while keeping each chain strictly sequential. Run three trials per arm. Stop every chain after task08; only the coordinator can open the recorded fix/no-fix holdout gate. A failed state carries forward unchanged unless the workspace/runtime is unusable.

Every initial turn has one complete public-check invocation after its edits. Read-only engineering authoring/context/impact are separate from application acceptance tests. Preserve the actual helper output and exact actor response before interpreting them. If the public helper fails, finish with `repair-needed` and dispatch a fresh actor using only the next prepared envelope with that exact public output. At most two extra turns share the original total 1800-second deadline. After exhaustion, record failure and carry the resulting state. A missing helper receipt is unavailable/protocol-invalid, never an inferred pass. There is no operator rescue.

Use attempt-specific immutable response files; pass the exact envelope digest and attempt index to `finish-task`. Native backend usage is unavailable through this interface. Operator transport records and helper JSONL are actual available receipts, not a claim of complete platform/read instrumentation. Never convert bytes into tokens or elapsed workflow time into attention.

The operator does not run hidden evaluation. The coordinator evaluates retained before-validation and final states after dispatch, without feeding those findings into later actors. Private Konfyra, publication and canonical adoption remain outside this experiment.

Parallel work uses only the frozen overlays and retained trial1 task06 snapshot. Each P-card has a fresh actor/fork; integration is lexical and mechanical. Conflicts or failed public validation may receive at most two fresh integration-repair turns under the same public-only contract. Preserve unresolved conflicts and do not hand-edit them.

Use `integrate-parallel --arena ARENA --protocol ARENA/protocol.yaml --project PROJECT --arm A|B --trial 1 --main-task-id 06 --parallel-task-ids P01,P02`. If it returns repair-needed, use its exact saved feedback with `prepare-integration-repair --arena ARENA --protocol ARENA/protocol.yaml --project PROJECT --arm A|B --trial 1 --attempt 1|2 --feedback-file FILE`. Finish that fresh turn with the normal `finish-task` command, integration run ID, task ID 08, exact attempt and digest. Never replay already applied original commits: the frozen integration plan, explicit applied ledger and literal cherry-pick origin trailers bind the remaining plan.

Every fresh leaf receives the exact saved current envelope path: `runs/<run-id>/<task-id>.attempt-<N>.envelope.yaml`. It may read only that envelope and its own actor workspace; no other arena file is authorized. Execute the envelope's `actor_prompt` and load its environment verbatim. Do not hand-transcribe long PATH values. The harness normalizes relative arena and protocol arguments before producing absolute actor, helper, manifest and evidence paths. The operator preserves the actual dispatch representation and never re-prepares an active turn to repair delivery.
