# Post-run descriptive analysis

`go run ./experiments/autonomous-ab-gauntlet/analysis --arena <external-arena> --out <new-report-directory>` reads an already populated arena and writes `report.yaml`. The output path must be outside the arena and must not exist. The collector verifies the frozen input hashes before reading records; it never writes to the arena, starts an actor, invokes validators/evaluators, or changes the frozen protocol, task cards, harness, or oracle.

The arena must contain the frozen `freeze.yaml` and inputs, `protocol.yaml`, `projects/<project>/project.yaml` and its selected task set, plus `runs/<run-id>/*.native.yaml`. Existing final evaluator YAML, `raw/<run-id>/<task>/helper*.jsonl`, response and receipt files, task snapshots, and captured workspace bytes are read only when present. Missing optional evidence stays unavailable. A missing task evaluator record is `unknown`. `manual-review-required` is `manual`; neither can count as pass. An evaluator pass without a completed actor record and successful public helper receipt is retained as the raw evaluation status but counted as `incomplete`. If `decisions/invalidation.yaml` explicitly matches the arena `freeze_digest`, uses `scope: all-native-records`, and sets `comparison_eligible: false`, every native record is retained and marked `invalidated` for counts; the report preserves the original evaluator and helper outcomes. Owner-decision tasks are excluded from implementation completion and counted in their own field. `owner_assessment` is populated only from a separate `decisions/<run-id>/<task>.yaml` with `assessment_status` set to `correct`, `incorrect`, `unnecessary`, `pending`, or `unknown`; the evaluator's owner-decision label is not an owner assessment.

For each task, file churn compares the exact recorded `base_revision` against the final captured snapshot workspace. The collector reads task-start bytes with `git show <base>:<path>` from that captured repository, includes new and deleted files, and computes byte and line additions/deletions from the file-level edit sequence. The report records both the base and final Git revisions. Each raw evidence reference includes its SHA-256 when the referenced file is retained. If the final snapshot or base commit is missing, churn is unavailable rather than reconstructed. The before-repair and final helper receipt vectors use the first and last preserved helper JSONL events. A before-repair hidden evaluation is included only when a separate `<task>.before-repair.evaluation.yaml` already exists; the collector does not rerun the evaluator against a snapshot.

Churn categories use explicit path-owner rules in `main.go`, based on the frozen seed layouts and their declared Markitect projections/check configuration: implementation, tests, authored governance, generated projections, check configuration, exceptions, and other. These are bookkeeping mappings over exact paths. They do not infer source semantics. Review or update these mappings only as a separately versioned analysis-tool change; they cannot redefine frozen scoring.

Context and impact are reported only when retained normalized YAML exists at `raw/<run-id>/<task>/context.yaml` with a string/map `entries` list, or `impact.yaml` with `directSubjects`/`direct_subjects` and `affectedEntries`/`affected_entries` lists. The report copies those keys as observed. Frozen `expected_affected` values are emitted separately and are not interpreted as achieved impact.

The report includes the SHA-256 of all Go source files in this analysis package. It contains descriptive task/group and repair counts, frozen expected-affected values, before-repair/final evaluation and helper vectors, helper receipts, and byte/line churn. Token, platform-call, read-audit, and attention fields each carry an explicit availability status; validation helper calls are reported separately. It makes no composite winner, byte/token/time/attention equivalence, productivity, human-attention, production-reliability, or statistical-significance claim. Native tokens, model/tool calls, read audit, and human attention remain unavailable unless those values were actually instrumented and retained.

Run the focused fixture checks with:

```powershell
go test ./experiments/autonomous-ab-gauntlet/analysis
```
