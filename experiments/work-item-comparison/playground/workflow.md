# Ordinary project workflow

Follow [the study contract](study-contract.md): the target is ordinary Codex CLI use, with a common outer control path per pair and declared approximation limits. A fixed station is a batch of incoming user work. Continue the actor's own project/session between batches; do not reset context or prompt each internal method step. Product MCP calls and inner Manager scheduling belong to the installed method.

1. **Prepare and bind setup.** Pin this Playground source and choose a case/runtime/method. Prepare a fresh isolated Git repository from shared common files and case source. Keep state and artifacts outside the actor checkout. Capture the seed commit, raw source hashes and setup interval. Conventional installs its ordinary native entrypoint and available tools. Markitect's owner installs its stable product, business model and generated instructions/Skills through the real product workflow, validates/corrects its own inputs, and commits setup. Freeze those bytes and setup time separately before any measured work. Initial model proposals are not a shortcut around current product installation.
2. **Freeze the prospective pair.** Fill freeze-template.json with both setup commits, explicit model/effort/provider for every role, tools, rights, limits, source/binary/config pins and support evidence. Publish the same 1/3/7/1 station scope and short task prompt. All requirements are visible from the beginning; `.study/station.json` declares the released wave. Keep execution disabled until the separate finite actual order arrives. No provider probes are part of preparation.
3. **Work normally.** Deliver the common prompt. The actor reads its project rules/backlog, plans as useful, uses ordinary native tools/helpers, diagnoses its failures, repairs and reruns affected checks, reviews and merges finished work to isolated main. Product errors are work to diagnose, not an automatic experiment stop. A real missing resource/support boundary, scope limit or human stop is reported with preserved state. Scientist does not translate product DTOs, prescribe successful output, repair product/candidate code or send semantic hints.
4. **Retain each station boundary.** The actor records completed/open items, tests, reviews, merge and team evidence in its own worklog and returns at the wave boundary. Capture main commit/tree, raw committed bytes, raw worktree bytes, branches/index/dirty state and receipts. Capture unfinished work separately; it earns no merged-main credit. After that snapshot, the controller changes only the declared next station and delivers the same backlog order from the current state. No repeated permission exchange for ordinary failure/repair. No new hidden requirements.
5. **Freeze at final handoff or finite end.** Preserve an immutable main checkout, Git bundle and separate worktree/unfinished evidence. Never normalize actor bytes in evidence or silently promote feature changes to main. Record reason, exact boundary and last released requirements. A freeze records state, not success. Do not advance after final freeze.
6. **Assess independently.** Give the assessor frozen main, public requirements/rules and released station. Run finite public checks plus independent public-spec boundary/regression/source/documentation review. No implementer transcript or other-arm result. The assessor reports findings without repairing the candidate. Keep method conformance, provider observations, technical validation and human acceptance separate.

Conventional setup appends `public/conventional/AGENTS.fragment.md` to the shared AGENTS.md. For Claude it also installs the plain `public/conventional/CLAUDE.md` router. Pin that setup commit and its files. Do not apply these method fragments to Markitect; its generated provider entrypoints belong to its genuine installation. Both installations retain the substantive shared project rules, public checks and backlog.

The mechanical helper exposes `prepare`, `snapshot`, `advance`, `freeze`, plus `record-setup` and `record-execution` for externally supplied metadata. It never invokes Codex, Claude or Markitect. `prepare` produces one seed and S1 metadata; it does not install either method. Extract the selected object from runtime-profiles.json into a pair-local profile file; the runtime profile catalog itself is not an installed configuration. Setup and later authorized actual execution remain externally owned. Authorization defaults to disabled; supplied metadata is a recorded claim, not a grant issued or verified by this helper. Execution recording never launches anything.

`snapshot` retains unsuccessful work, any current branch/detached HEAD, immutable main and dirty/unfinished state separately. `advance` requires the retained boundary and a clean index, then modifies only `.study/station.json`, leaving that declared controller delta uncommitted for normal actor integration. It does not stage or commit the actor's other changes. `freeze --reason TEXT` closes at any released station, including early blocked or finite-end closure; no later transition is allowed. The helper cannot establish absence of active processes: the controller must stop/join its own actors before capture and record that boundary. Copy/hash and Git-state stability checks detect observed mid-capture changes, but are not OS isolation.

Prospective source-local command shape (no execution authorization follows from it):

```powershell
python -B lifecycle.py prepare --seed public --repo CASE_PATH --audit AUDIT_PATH --case roombook --method Conventional --profile PAIR_PROFILE.json
python -B lifecycle.py record-setup --audit AUDIT_PATH --owner OWNER --status complete --details SETUP_RECEIPT.json
python -B lifecycle.py snapshot --repo CASE_PATH --audit AUDIT_PATH
python -B lifecycle.py advance --repo CASE_PATH --audit AUDIT_PATH
python -B lifecycle.py freeze --repo CASE_PATH --audit AUDIT_PATH --reason "finite end"
```

`CASE_PATH` and `AUDIT_PATH` are fresh separate destinations outside the public source tree. Snapshot directories contain `immutable-main`, `worktree`, `actor-state`, `history.bundle`, `snapshot.json` and its hash envelope `binding.json`. Raw index/diffs/refs are retained; main source bytes are checked against committed blobs after a locally configured LF-preserving clone checkout. Hash binding makes subsequent change detectable; the filesystem does not make an output tamper-proof.

Each prepared checkout has a unique `.study/run-id` for its audit binding. That identity metadata is recorded separately from shared business-input equality: compare the copied common/case source hashes, not equality of run IDs or method setup trees. Setup changes must not silently alter those shared requirements.

All run files belong to one controller. Every output destination is new; failures retain partial artifacts for diagnosis. Use a fresh output path for retry and retain the failed attempt. No automatic retry or broad cleanup. Shared host paths are an instruction boundary, not OS isolation. Ordinary project history is available; private assessments, other arms and historic solution/result artifacts are excluded from actor inputs.

At a future S3, let agents choose decomposition, prompts and branch ownership themselves. Require actual overlapping executing intervals and integrated contributions; a helper request, review-only helper or several sequential turns do not prove a team. Record unavailable native overlap/start/usage telemetry as unknown. Do not disable native tools to manufacture an enforceable resource claim. Document controller-enforced limits separately from post-dispatch observations and cooperative limits.

## Optional Conventional controller

After a later externally frozen finite actual order, the [Conventional wrapper](conventional/README.md) may control ordinary work via CLI or MCP over a native CLI or App Server backend. Start one fresh context; resume its owned latest native session across station releases. Pass the common user request unchanged; controller MCP belongs outside the actor. Preserve wrapper receipts in the external audit, then capture source/main/WIP through lifecycle.py independently. A completed native turn is not task success. No source-preparation command starts a real actor, and no transport choice or example file is an actual grant.
