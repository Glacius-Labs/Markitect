# Native App entry for the existing nest

This is a prospective, manually orchestrated entry using the available `collaboration` tools. It does not call a Python/CLI agent API. Original native CLI pilots stay terminal and retain their original sources, profile receipts and failure accounting. The App uses a different runtime. A new exact enabled owner grant is required before any measured App actor starts.

`app_ledger.py` only reserves and records case-local entries. It imports the existing nest file/Git helpers and uses the existing lock. It invokes no model, provider or collaboration tool. Reservations are cooperative: actors with normal App tools can bypass this file, so it is not proven hard enforcement, OS isolation or a global concurrency cap.

For a fresh primary, helpers/inner roles and final assessor, reserve an entry before the native call and invoke `collaboration.spawn_agent` with `fork_turns="none"`, `model="gpt-6-luna"`, and `reasoning_effort="high"`. Record the exact returned own handle, task name, call result and time. No cwd argument exists in this tool. A continuation uses only an explicitly returned own handle through `followup_task`, after reserving another outer entry. Failed requests still consume reservations; record actual tool call/model start separately and never infer a turn from a reservation alone. `send_message` to an already active own actor does not start an idle actor; use it only for resource/stop coordination, never case advice. Do not enumerate or message unrelated agents.

The initial semantic task is exactly the existing `nest.PROMPT`; a fixed continuation is exactly `nest.CONTINUE`. Add only execution bindings: own absolute project path, own public rules, model/resource bounds and own ledger location. No solutions, private Scientist/Root histories, previous evaluations, memory or other case paths are provided. Fresh spawn excludes parent turn history by the documented `fork_turns` mechanism. Common system/developer/workspace instructions and tools may still be inherited. The app task's supplied CWD is the parent Markitect checkout; directing normal file/shell calls to the fresh case does not change that inherited CWD or provide OS isolation. Actual inherited CWD, applicable instruction origins and any real foreign exposure must be recorded honestly at the actual start. Do not claim their absence from a prospective contract. If private inherited exposure is observed, stop and report that boundary rather than copying it into the case. Actors do not read old studies/chats/memory or parent repository documentation.

All measured helper/inner-role starts use the same fresh model/high configuration and count toward the shared finite ceiling of 72 App starts. A fresh spawn and an idle followup turn each consume one ledger reservation. Model sampling/provider requests within a turn are separate unknown quantities unless genuine receipts exist; they are not manufactured from the start count. Four concurrent measured agents and depth two are cooperative per-cell limits. Parent Scientist orchestration and independent Design work are not measured case helpers; no uncounted case helper is permitted. Helpers reserve before spawning and record handles/results in this same ledger. Requests/results and actual observed model turns remain distinct.

The first outer reservation starts the case clock only with a full 7200 seconds remaining before the immutable owner end. Implementation has 5400 seconds; station slices end at offsets 1350/2700/4050/5400 seconds, at most two outer entries per station and eight overall. Reserve all helpers inside the appropriate phase/station window; no refill. Final assessment has 1200 seconds and ends no later than offset 6600. Capture/closure has the remaining 600 seconds. Check clocks before each tool call and after waits; waits stay at most 60 seconds. At deadlines, interrupt only recorded own handles; reconcile their known owned shell/process jobs before snapshot/final assessment. App interruption is a turn interruption, not proof that every process or provider request stopped. Unknown cleanup stays unknown and prevents another actor from launching. Do not detach persistent jobs or inspect global process inventories.

The Scientist reads only completion metadata, own lifecycle/resource receipts and immutable snapshot paths to dispatch stations. Matching `complete` triggers the existing `nest.snapshot` and `nest.advance`; no matching completion permits at most the original one fixed continuation, then freeze. A real tool policy blocker closes implementation immediately; no continuation, alternate transport or case repair is authorized by that blocker. No semantic evaluator feedback or adaptive Scientist coaching is sent to the implementer. The original source, public backlog, rules and 1/3/7/1 stations remain unchanged.
