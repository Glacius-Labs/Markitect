<!-- BEGIN MARKITECT MODEL-FIRST -->
When a short Work Item, issue, bug, or idea arrives, use markitect project with .markitect/project.yaml, read the repository-root .markitect/workflows/model-first.md and follow it as the default. Inspect markitect project schema for the model contract and markitect project index --repo PATH for current Manager identities. The workflow covers a persistent decision ledger, iterative brownfield reverse-modeling, repository-policy acceptance at a committed model revision, computed first-scope readiness, bounded Manager and reviewer responsibilities, Plan/Run/Verify/Apply, first-success completion, and resuming persisted work without replay.
<!-- END MARKITECT MODEL-FIRST -->
